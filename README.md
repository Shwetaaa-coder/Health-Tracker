# 🥗 Healthy Habits Tracker

A web application designed to help users build and maintain healthy daily routines by tracking habits such as hydration, exercise, sleep, nutrition, and other wellness activities.

The application provides an easy-to-use interface for recording daily habits and monitoring progress over time, helping users stay consistent with their health goals.

## ✨ Features

* 📋 Create and manage daily healthy habits
* ✅ Mark habits as completed
* 📊 Track daily and weekly progress
* 🔥 Monitor habit consistency and streaks
* 💧 Track hydration and other wellness activities
* 🏃 Track exercise and physical activities
* 😴 Monitor sleep-related habits
* 📱 Responsive and user-friendly interface
* 📈 View progress and habit completion

## 🛠️ Tech Stack

* **Frontend:** React.js, JavaScript, HTML5, CSS3
* **Styling:** Tailwind css
* **Database:** Firebase
* **Tools:** Git, GitHub

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Shwetaaa-coder/Health-Tracker.git
```

2. Navigate to the project directory:

```bash
cd healthy-habits-tracker
```

3. Install the dependencies:

```bash
npm install
```

4. If the project uses environment variables, create a `.env` file and add the required configuration.

5. Start the development server:

```bash
npm start
```

6. Open the application in your browser at the local URL shown in the terminal.
